# IDRiD Localization Annotations

This directory contains the original optic-disc and fovea center-coordinate
CSV annotations from the Indian Diabetic Retinopathy Image Dataset (IDRiD).

## Source

Porwal, P., et al. (2018).
Indian Diabetic Retinopathy Image Dataset (IDRiD):
A Database for Diabetic Retinopathy Screening Research.
Data, 3(3), 25.

Paper: https://doi.org/10.3390/data3030025
Official dataset: https://idrid.grand-challenge.org/Data/
